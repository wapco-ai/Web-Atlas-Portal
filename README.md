# وب‌سایت وب اطلس پویا

نسخه کامل وب‌سایت فارسی شرکت وب اطلس پویا، ساخته‌شده با React، Vinext و Vite.

## اجرای محلی در ویندوز

پیش‌نیاز: Node.js نسخه 22.13.0 یا جدیدتر.

```cmd
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده در ترمینال (معمولاً `http://localhost:5173`) را در مرورگر باز کنید.

برای مشاهده سایت روی موبایل متصل به همان شبکه:

```cmd
npm run dev -- --host
```

## بررسی نسخه نهایی

```cmd
npm run lint
npm run build
```

کد صفحه اصلی در `app/page.tsx`، استایل‌ها در `app/globals.css` و تصاویر در `public/assets` قرار دارند.

پوشه `node_modules` تولیدشده است و نباید داخل ZIP، Git یا نسخه پشتیبان پروژه نگهداری شود. هر زمان لازم باشد با `npm install` دوباره ساخته می‌شود.
